## Findings considered and rejected

- **Hardcoded dev-default secrets (BETTER_AUTH_SECRET / SUPER_ADMIN_PASSWORD
  fallbacks)**: by design — `assertProductionEnv()` in
  `packages/config/src/env.ts:85-103` rejects missing vars AND the known dev
  defaults in production. Dev fallbacks + prod fail-fast is a sound posture.
- **better-auth cookie/CSRF posture**: defaults appropriate, `trustedOrigins`
  locked (verified across server fns during the security audit).
- **CSV formula injection**: staged cells render through React escaping; no
  CSV/Excel export of user fields exists.
- **Committed `.env`**: gitignored, placeholder values only.
- **IDOR on order/sub-order/notifications/wishlist reads**: verified clean —
  buyer/seller/admin scoping enforced server-side.
- **Base UI `nativeButton` console warning on render-prop Links**: benign
  dev noise; setting `nativeButton={false}` flips Links to `role="button"`
  (regression — documented in `button.tsx`).
- **Money-formatting duplication**: not duplicated — centralized in
  `packages/config` with tests.
- **Wishlist/notifications "missing pages"**: both exist and are complete.
- **Fake-gateway/COD-only payments, Stripe Connect, per-line refunds,
  scheduled payouts, notification prefs, audit log**: deliberate phase-3
  parking lot (`plans/phase3/plan-10.md`) — do not re-report.
